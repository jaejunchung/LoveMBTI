# 설문 원문과 채점표

20개 문항 전체입니다. 응답자는 두 상황 중 **더 화나는 쪽**을 고릅니다.
괄호 안의 글자는 그 선택지를 골랐을 때 올라가는 점수(= 싫어한 유형의 반대 성향)입니다.

### 1. 애인이 100일 기념으로 준 선물
`N / S` · 선물

- **A.** 밤새 종이로 접은 목걸이를 건네며 “정성이 중요하지”라고 말하는 유형 → **+S**
- **B.** 당근에서 산 걸 숨기고 “새 거 샀어”라며 목걸이를 주는 유형 → **+N**

### 2. 선물과 함께 건네는 편지
`N / S` · 편지

- **A.** 2페이지짜리 정성 편지를 주고, 몇 번째 줄 몇 번째 단어였냐며 집요하게 시험하는 유형 → **+S**
- **B.** “사랑해” 단 한 단어만 적어 보내는 유형 → **+N**

### 3. 하루 동안의 연락 빈도
`E / I` · 연락

- **A.** 화장실 가는 것까지 보고하고, 5분 답장이 없으면 부재중 3통을 남기는 유형 → **+I**
- **B.** 하루 카톡이 “ㅇㅇ”, “ㅋㅋ” 두 개가 전부고 전화는 다음 날 “잤어”로 끝나는 유형 → **+E**

### 4. 기념일을 챙기는 방식
`J / P` · 기념일

- **A.** 22일·33일·100일 전야제까지 챙기며 매번 이벤트와 선물을 기대하는 유형 → **+P**
- **B.** 1주년 당일 저녁 8시에 “아, 오늘이었어?” 하는 유형 → **+J**

### 5. 데이트 코스를 정하는 방식
`J / P` · 데이트

- **A.** 분 단위 타임테이블을 짜오고, 10분 늦으면 일정 틀어졌다며 예민해지는 유형 → **+P**
- **B.** 3년째 “아무거나”라고 하고는 막상 가면 시큰둥한 유형 → **+J**

### 6. 싸웠을 때의 태도
`J / P` · 다툼

- **A.** 새벽 4시까지 “오늘 안에 끝내야 한다”며 지난 대화를 전부 소환하는 유형 → **+P**
- **B.** 읽씹하고 3일 잠수한 뒤 아무 일 없다는 듯 “밥 먹었어?” 하는 유형 → **+J**

### 7. SNS에 드러나는 우리 관계
`E / I` · SNS

- **A.** 자는 사진, 우는 사진까지 스토리에 올리고 모든 게시물에 나를 태그하는 유형 → **+I**
- **B.** 2년을 사귀었는데 피드에 내 흔적이 0이고, 아는 사람을 만나면 “그냥 친구”라고 소개하는 유형 → **+E**

### 8. 전 애인 이야기가 나왔을 때
`T / F` · 과거

- **A.** “전에 만나던 사람은 이럴 때 이랬는데”라는 비교를 습관처럼 하는 유형 → **+F**
- **B.** 과거 연애는 전부 “기억 안 나”로 덮고 끝까지 숨기는 유형 → **+T**

### 9. 데이트 비용을 다루는 방식
`T / F` · 비용

- **A.** 매번 계산기를 두드려 1원 단위로 정산하고, 입금이 늦으면 리마인드를 보내는 유형 → **+F**
- **B.** 선물 사주고 플렉스하다가 월말에 “카드값 좀 보태줄 수 있어?” 하는 유형 → **+T**

### 10. 서로의 친구 관계
`E / I` · 친구

- **A.** 내 친구 모임마다 따라와 옆자리를 사수하고 단톡방까지 들어오는 유형 → **+I**
- **B.** 1년 넘게 자기 친구는 한 명도 안 보여주며 “겹치면 불편해”라고만 하는 유형 → **+E**

### 11. 질투를 표현하는 방식
`T / F` · 질투

- **A.** 이성 연락처 삭제를 요구하고 카톡 목록을 주기적으로 확인하는 유형 → **+T**
- **B.** 내가 이성 친구와 1박 여행을 간다 해도 “응, 재밌게 놀다 와”로 끝나는 유형 → **+F**

### 12. 내 변화를 알아채는 정도
`N / S` · 관찰

- **A.** 매일 복붙한 듯 “오늘도 예쁘다/멋있다”라고 하지만 뭐가 어떻게 예쁜지는 대답 못 하는 유형 → **+S**
- **B.** 머리를 20cm 자르고 염색까지 했는데 3주째 모르는 유형 → **+N**

### 13. 내가 아플 때의 반응
`T / F` · 간병

- **A.** 감기 기운이 있다니까 응급실로 끌고 가 보호자 행세를 하고 회사에까지 전화하는 유형 → **+T**
- **B.** 응급실 다녀왔다는 말에 “약 먹어” 한 줄 보내고 다음 날 안부도 없는 유형 → **+F**

### 14. 미래 이야기를 꺼내는 방식
`N / S` · 미래

- **A.** 세 번째 데이트에서 결혼식장 견적과 아이 이름 후보를 공유하는 유형 → **+S**
- **B.** 2년을 사귀고도 미래 얘기만 나오면 “지금이 좋잖아”로 매번 넘기는 유형 → **+N**

### 15. 잘못했을 때 사과하는 방식
`T / F` · 사과

- **A.** 무릎 꿇고 울며 과하게 자책해서 결국 내가 달래주게 만드는 유형 → **+T**
- **B.** “미안. 됐지?” 한마디 하고 바로 게임에 접속하는 유형 → **+F**

### 16. 내 취미를 대하는 태도
`E / I` · 취미

- **A.** 내 취미를 전부 따라 시작해서 나보다 잘하려 들고 훈수까지 두는 유형 → **+I**
- **B.** “그거 왜 해? 돈 아깝게”라며 한 번도 관심을 주지 않는 유형 → **+E**

### 17. 집에서 함께 먹는 밥
`N / S` · 식사

- **A.** 재료비 10만 원짜리 실험 요리를 차려놓고 30분간 맛 평가를 요구하는 유형 → **+S**
- **B.** 1년 내내 배달만 시키고 메뉴 고르기도 결제도 전부 내 몫인 유형 → **+N**

### 18. 둘이 떠나는 여행
`J / P` · 여행

- **A.** 항공·숙소·식당을 혼자 다 정해 통보하고, 의견을 내면 “이미 결제했어”로 막는 유형 → **+P**
- **B.** 공항에 도착해서야 “어디 갈지는 가서 정하자”라고 하고 숙소도 안 잡아둔 유형 → **+J**

### 19. 가족에게 나를 소개하는 문제
`E / I` · 가족

- **A.** 사귄 지 한 달 만에 부모님 댁에 데려가 상견례 분위기를 만드는 유형 → **+I**
- **B.** 2년째 가족에게 내 존재를 숨기고 명절엔 아예 연락이 끊기는 유형 → **+E**

### 20. 휴대폰과 사생활의 경계
`J / P` · 사생활

- **A.** 자기 폰 비번을 알려주며 “서로 보는 거잖아”라고 매일 내 폰을 검사하는 유형 → **+P**
- **B.** 폰을 늘 엎어두고 알림이 뜨면 급히 가리는 유형 → **+J**
