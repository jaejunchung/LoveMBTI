# 설문 원문과 채점표

전체 40문항입니다. 응답자는 두 상황 중 **더 화나는 쪽**을 고르고, 화살표 뒤 글자가 그때 올라가는 점수(= 싫어한 유형의 반대 성향)입니다.

`기본`은 20문항 빠른 버전에도 포함된 문항, `심화`는 40문항 정밀 버전에서만 나오는 문항입니다. `×2`가 붙은 문항은 가중치 2점입니다.

## 축별 배분과 총점

| 축 | 빠른(20문항) | 정밀(40문항) | 가중치 문항 |
|---|---|---|---|
| E / I | 5문항 5점 | 10문항 11점 | 22번 |
| N / S | 5문항 5점 | 10문항 11점 | 28번 |
| T / F | 5문항 5점 | 10문항 11점 | 32번 |
| J / P | 5문항 5점 | 10문항 11점 | 36번 |

두 버전 모두 축별 총점이 홀수라 동점이 구조적으로 나오지 않습니다.
정밀 버전은 축당 10문항(짝수)이므로, 축의 성격을 가장 선명하게 가르는 문항 하나에 2점을 주어 11점으로 맞췄습니다.
문항을 더 늘리거나 줄일 때도 **축별 총점이 홀수**인지만 확인하면 됩니다.
